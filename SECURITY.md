# Security Policy

Report vulnerabilities to contact@voxhash.dev or security@licensechain.app.

## Dependabot alerts enablement

GitHub Dependabot **security alerts** are currently disabled for this repository (API returns HTTP 403). To enable:

1. Open https://github.com/LicenseChain/LicenseChain-NodeJS-SDK/settings/security_analysis
2. Enable **Dependabot alerts** and **Dependabot security updates**
3. Confirm the token/org policy allows vulnerability alerts for this repository

Dependabot version-update PRs may still open via `.github/dependabot.yml` even when security alerts are disabled.
